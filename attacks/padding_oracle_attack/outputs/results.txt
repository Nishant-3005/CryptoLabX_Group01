Attack Explanation:
  In CBC decryption, P_i = AES_inv(C_i) XOR C_{i-1}.
  By modifying C_{i-1} and checking if the oracle accepts
  the padding, we can deduce the intermediate value I_i
  byte-by-byte, then XOR with the real C_{i-1} to get P_i.

Prevention:
  1. Use authenticated encryption (AES-GCM) instead of AES-CBC
  2. Apply Encrypt-then-MAC (HMAC verified before decryption)
  3. Return generic errors -- never reveal padding validity
